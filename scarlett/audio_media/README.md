# Audio, Input & Media (`scarlett/audio_media/`)

Console audio, controller input, video playback, and FidelityFX translation modules.

## Modules

- `xaudio2_9.dll` (Ordinal #1 `XAudio2Create`) and `AcpHal.dll` (Hardware Opus / XMA2 / PCM ring-buffer DMA).
- `GameInput.dll` (Ordinal #1 `GameInputCreate`, 4-motor impulse trigger rumble).
- `Bink2Scarlett.dll` and `amd_fidelityfx_loader_xbox.dll` / `amd_fidelityfx_upscaler_xbox.dll`.
